Developers
==========

Here you find everything you need to implement the BankID services in a secure and user friendly way.

## Optional

- [Digital ID Card OpenAPI spec](https://developers.bankid.com/assets/openapi/openapi-id-card-v2.yaml): Full OpenAPI specification for the /rp/v1/verify endpoint.

- [Auth & Sign OpenAPI spec](https://developers.bankid.com/assets/openapi/openapi-auth-sign-6.1.11.yaml): Full OpenAPI specification for /auth, /sign, /collect, /cancel, /payment and related endpoints.

## Use cases

- [Mobile BankID on the same device](https://developers.bankid.com/use-cases/mobile-bankid-on-the-same-device): Use case descriptions for when a service is visited on the same device as the BankID is used on.

- [Mobile BankID on another device](https://developers.bankid.com/use-cases/mobile-bankid-on-another-device): Use case description for the BankID flow when the user visits a service on one device and use their BankID on another device. 

- [Verification of digital ID card](https://developers.bankid.com/use-cases/verification-of-digital-id-card): Use case description and flow chart for verification of a digital ID card. 

- [Fallback](https://developers.bankid.com/use-cases/fallback): To provide the best solution for the user a fallback option is recommended. See an example here.
